# GatsbyZero個人のKo-fi設定

1. GatsbyZero名義の管理アカウントでKo-fi Standardを選ぶ。表示通貨をJPY、主導線を一回限りの任意支援にする。
2. 紹介文: 「GatsbyZeroの音楽・映像・インタラクティブ作品の制作を任意で支援できます。Astronaut Academyは無料で、支援の有無で教材・参加権・回答の優先度は変わりません。本作はNASAの制作・承認・推奨を受けていません。」
3. NASAの写真、モデル、ロゴ、映像をKo-fiの支援訴求素材に使わない。Ko-fiの画像はGatsbyZero自身が権利を持つ創作物から選ぶ。
4. 公開の制作記録と任意参加の投票を使う。投票は開発の最終決定権を移すものではない。Issueや変更履歴はGitHubに残す。
5. 公開URLは[ko-fi.com/gatsbyzero](https://ko-fi.com/gatsbyzero)。`.env.production`でGitHub Pagesとitch.ioの両ビルドへ同じURLを設定する。双方の非公認表示とリンク先を実際に確認する。

2026-09-27にKo-fiの公開ページでGatsbyZero名義、JPY、Ko-fi Standard、月額支援オフ、一回限りの支援（最低100円）を確認した。紹介文と支援後メッセージに無料アクセス・参加権との分離、NASA非公認を記載した。決済テストは行っていない。

Ko-fi公式の[料金表](https://help.ko-fi.com/hc/en-us/articles/360002506494-Does-Ko-fi-take-a-fee)ではStandardの一回限りの支援にも5%のサービス料がかかり、決済手数料は別途かかる。[クリエイター検索はない](https://help.ko-fi.com/hc/en-us/articles/27035616108957-Can-I-search-for-creators-on-Ko-fi)ため、発見経路は作品、制作記録、既存のアーティスト発信先から作る。支援率や投稿別の帰属は実測できる場合に限り記録する。
