# NASA and creative asset register / 素材台帳

The exact source URL, attribution, source page, and generated file mapping for each included NASA asset are in [public/assets/manifest.json](public/assets/manifest.json). The build contains: ISS and EMU 3D models; Earth day, night, and cloud maps; Moon color and elevation data; a star map; and a title photograph. The visualizations simplify and recolor source data for learning.

| Included material | Source/credit | File key |
| --- | --- | --- |
| ISS model | [NASA VTAD](https://science.nasa.gov/resource/international-space-station-3d-model/) | `iss`, `issHd` |
| EMU model | [NASA / Michael D. Carbajal](https://science.nasa.gov/3d-resources/extravehicular-mobility-unit/) | `emu` |
| Earth maps | [NASA Visible Earth](https://visibleearth.nasa.gov/images/73909), [NASA Earth Observatory](https://earthobservatory.nasa.gov/features/NightLights) | `earthDay*`, `earthNight*`, `earthClouds2k` |
| Moon maps/elevation | [NASA SVS / LRO](https://svs.gsfc.nasa.gov/4720) | `moonColor*`, `moonNormal2k`, `lunarSouthPole` |
| Stars | [NASA SVS](https://svs.gsfc.nasa.gov/4851) | `stars*` |
| Title photograph | [NASA / ISS Expedition 71](https://images.nasa.gov/details/iss071e581260_alt) | `titleOrbit` |

The title photograph includes the identifiable profile of NASA astronaut Tracy C. Dyson, as [NASA Johnson's published caption](https://www.flickr.com/photos/nasa2explore/54178473907) confirms. Use it only inside the free educational game with attribution; **do not reuse it in external promotional images or fundraising material without rights review**. Live archive search results are **not embedded** in lessons, because a result may include third-party rights. The game links to the NASA archive for optional exploration.

The existing 15-second trailer and gameplay stills other than the original scene identified below are **not cleared for promotion** by inclusion here. Before release announcements, review every shot, music cue, person, logo, and NASA media item. Do not use NASA insignia or suggest endorsement. See [NASA Images and Media Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).

## Original launch artwork

`launch/assets/cover.svg` and `cover.png` are original abstract orbital artwork created for GatsbyZero's itch.io cover with Codex assistance. They do not contain NASA media. The SVG drawing was produced in this project's AI-assisted authoring session, so the cover is disclosed as AI-assisted graphics on itch.io. `launch/assets/t38-scene.png` is an unretouched render of the game's own conceptual T-38 scene, copied from the existing promo capture. The conceptual jet and environment are generated in game code; this image contains no NASA photograph, model, logo, or person. It is a scene render rather than a screenshot of the playable interface.

`launch/assets/robotics-gameplay.png` is an actual in-game robotics exercise screenshot. The arm, vehicle, and UI are original conceptual designs. Its background uses the [NASA Scientific Visualization Studio star map](https://svs.gsfc.nasa.gov/4851), credited in the game and here. It contains no NASA employee, insignia, or logo. It is suitable for a factual game listing with NASA credit and a clear non-endorsement notice; it is not a Ko-fi fundraising image.
